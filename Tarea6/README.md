## Tarea 6 
Este proyecto consiste en la implementación de un Árbol B en Python, configurable por el grado mínimo ingresado por el usuario.

El programa permite realizar operaciones básicas sobre el árbol, como insertar claves, buscar claves y eliminar claves. Además, permite cargar datos desde archivos CSV y generar una representación gráfica del Árbol B utilizando Graphviz.

El objetivo principal de esto es demostrar el funcionamiento de un Árbol B como estructura de datos eficiente para almacenar, buscar y organizar información.

---

## Funcionalidades del programa

El programa cuenta con un menú principal que permite realizar las siguientes operaciones:

1. Configurar el grado mínimo del Árbol B.
2. Insertar claves manualmente.
3. Buscar claves dentro del árbol.
4. Eliminar claves del árbol.
5. Cargar datos desde archivos CSV.
6. Mostrar la estructura del árbol en consola.
7. Generar una representación gráfica del árbol usando Graphviz.
8. Salir del programa.

---

## Requisitos del sistema ejecutable

Para ejecutar este proyecto se necesita tener instalado:

- Python 3
- La librería `graphviz`
- Graphviz instalado en el sistema operativo

## CARGAR LOS ARCHIVOS CSV

- seleccionar la opcion 4 en las opciones del menú
- ingresar "datos1.csv" "datos2.csv" o "datos3.csv" para que se carguen en el programa
- luego de ingresar los datos, seleccionar la opcion 5 para mostrar el arbol en consola, o la opcion 6 para enerar imagen del árbol.
